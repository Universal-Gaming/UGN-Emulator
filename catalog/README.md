# UGN Emulator — complete title index

**41,408 metadata entries in 16 console archives.** These are real console game title/edition names and regions, not commercial ROMs or BIOS files.

Adapted from [Libretro Database](https://github.com/libretro/libretro-database), © the original contributors, distributed under [Creative Commons Attribution–ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).

Changes made by UGN: selected 16 console DAT sources, extracted names and regions, removed duplicates and some pre-release/diagnostic editions, sorted entries and converted them into JSON files used by browser search. This adapted metadata retains the CC BY-SA 4.0 license.

The presence of a title in this directory does not mean UGN hosts, licenses, or endorses that game. For an unhosted title, visitors must select a game file that they are legally entitled to use, from their own device. No commercial ROMs or firmware are linked or redistributed by this catalog.

Game-cover images are requested on demand from the [Libretro thumbnails service](https://thumbnails.libretro.com/) as external references and may be unavailable. Copyright in the individual artwork remains with its original owner; the CC BY-SA metadata license does not extend to cover images.

Generate: `python scripts/generate_catalog.py`. Metadata updates are reproducible through `.github/workflows/catalog.yml`.
